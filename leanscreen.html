leanscreen

A faithfulness screen for Lean 4. It catches formal statements that compile but don’t say what the mathematics says. Run it on a file, in CI, or inside Claude Code while you draft.

pip install leanscreen
GitHub → Request certification
leanscreen check Demo.lean exists_perfect_number: REJECTED flags=deterministic-vacuous:reflexive-goal even_add_even: no defect found

The first theorem compiles and is even provable. Its docstring promises a perfect number; its statement says ∃ n : ℕ, n = n. The compiler has no objection. That gap is what leanscreen catches.
