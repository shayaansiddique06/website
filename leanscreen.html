Open tooling · MCP

leanscreen
The screen you run while you draft.

A calibrated faithfulness screen for informal–Lean 4 statement pairs, served over MCP so Claude Code, Claude Desktop, or any MCP client can check statements as they’re written. The same detector stack behind our benchmark audits — with its measured error rates attached to every answer.

GitHub → Request certification
The one thing to understand

This screen may only reject. A pass means “nothing found” — never “faithful.” Only a human certifies.

Two tools

check_fast

Deterministic only: lints for unused binders, trivially satisfiable existentials, pinned witnesses, suspicious ℕ-arithmetic; vacuity checks for reflexive and True goals and withheld declarations; and real Lean 4 elaboration against your own mathlib environment.

Call it constantly. It costs nothing and answers in a tenth of a second once mathlib is warm.

  • networknone — no API key
  • latency, warm REPL~0.1s per statement
  • evidence classdeterministic

check_deep

Everything in check_fast, plus two independent LLM judges under strict consensus — a back-translation judge and a clause-by-clause checklist judge on separate models — and an adversarial counterexample probe.

Call it deliberately, before something ships. Runs on your ANTHROPIC_API_KEY; every response ranks its evidence, and a single-judge flag is explicitly labeled as below the reporting bar.

  • judges per pair2, strict consensus
  • measured cost$0.17–0.27 / statement
  • evidence laddercounterexample > deterministic > consensus
What it does not guarantee

We publish the instrument’s own error rates. Here they are.

Miss rate · theorems 17.0%

Human-rejected theorems that still pass

Against 886 frozen human verdicts, statements a reviewer had rejected passed the full screen 17.0% of the time for theorems.

Miss rate · definitions 35.6%

Definitions are harder

Human-rejected definitions passed 35.6% of the time. If your corpus is definition-heavy, weigh a pass accordingly.

False-flag rate 15–18%

Certified pairs still get flagged

Statements a human had certified faithful were flagged 15–18% of the time. Every flag is a candidate for review, not a verdict.

Probe honesty 4 of 5

The probe confabulates

On one PutnamBench hand-check, four of five counterexamples the probe produced were wrong. Both judges are Anthropic-family models, so correlated blind spots cannot be ruled out.

Install

One line

Python ≥ 3.12. Four runtime dependencies. Without a Lean project it still runs — and says plainly that elaboration was skipped. With one, statements elaborate for real against your mathlib; the REPL warms once at startup, in the background. 

pip install git+https://github.com/ibrahimmian36/leanscreen

Point your client at it

Claude Code reads .mcp.json in your project; Claude Desktop uses claude_desktop_config.json. The key is needed for check_deep only. 

{
  "mcpServers": {
    "lean-faithfulness-screen": {
      "command": "leanscreen",
      "env": {
        "LEANSCREEN_LEAN_PROJECT_PATH": "/path/to/your/mathlib-project",
        "LEANSCREEN_LEAN_REPL_PATH": "/path/to/repl/.lake/build/bin/repl",
        "ANTHROPIC_API_KEY": "…"
      }
    }
  }
}
