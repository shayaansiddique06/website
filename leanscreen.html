Open tooling

The statement compiles.
Does it say the right thing?

A faithfulness screen for Lean 4. It catches statements that compile but don’t say what the mathematics says.

pip install leanscreen
GitHub → What it catches

The compiler has no objection.
leanscreen does.

leanscreen check Demo.lean exists_perfect_number: REJECTED flags=deterministic-vacuous:reflexive-goal even_add_even: no defect found

The first theorem compiles, and is even provable. Its docstring promises a perfect number; its statement says ∃ n : ℕ, n = n.

Two screens.
One rule: it can only reject.

  1. 01

    Fast screen

    Lints, vacuity checks, and elaboration against your own mathlib. Free, local, a tenth of a second — command line, CI, or inside Claude over MCP.

  2. 02

    Deep screen

    Two independent judges read the Lean against the English, and a probe hunts for a counterexample. Run it before something ships.

  3. 03

    Calibrated, and it says so

    Measured against 886 human verdicts. Every response says what a verdict is worth. A pass is never a certification.

The screen rejects.
People certify.

When a statement has to be right, we put an expert reviewer behind it. The screen is how it starts.
